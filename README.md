# hamzatzortzis.com: design mockups

Three design directions for a new website for Hamza Andreas Tzortzis, each shown as a home page and an essay page. Shared for review.

**This is not his official website.** Wording marked † is draft and has not been approved by him. Endorsements are quoted from his old book page until they are re-cleared.

- Live: https://jamilasad.github.io/hamzatzortzis-mockups/
- 1 Marginalia (recommended): `marginalia/`
- 2 The Lit Window: `lit-window/`
- 3 In Question: `in-question/`

Static HTML, CSS and a little JavaScript; no build step. Typefaces are free stand-ins from Google Fonts. The only image is the book cover of *The Divine Reality*.
